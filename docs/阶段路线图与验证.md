# 验证状态与后续路线

## 当前基线

当前本地版本已实现研究、双页面内容、批次工作台和图片交付。用户已认可核心功能；具体任务的图片批准仍由 Web 中的版本确认决定，项目状态不自动批准任何图片。

阶段 A/B/C/D 是开发顺序，正式使用不需要按阶段切换。当前流程和契约以 [README](../README.md)、[产品需求](阶段C-D产品需求.md) 和 [SDD](阶段C-D技术架构与实施SDD.md) 为准。

## 已验证范围

- 自动回归覆盖输入候选／门禁、模拟访谈、规划、引用定位、分类与缺失路径、编辑基线、预算、渲染、批次恢复和图片会话。
- 已有 Windows 真实 DeepSeek 搜索／读取、文本与视觉调用、Seedream 图片生成和参考图修改样例。
- Blog 双候选各有真实生成和读图样例；程序检测 PNG／比例，详情图样例验证真实 alpha。
- 前端契约测试覆盖跨任务草稿、两卡意见、单图引用、选图／确认和下载入口；这不等于真实浏览器完整布局或键盘验收。
- 发布整理后的测试及网络／启动验证见 [发布整理验证](release-checks.md)。

## 验收规则

| 范围 | 必须保留的判断 |
|---|---|
| 输入与审批 | 当前来源独立；候选差异需明确确认；过期版本拒绝 |
| 证据与事实 | 引用存在不等于语义支持；品类／竞品不是本商品事实；缺失路径确实可核对 |
| 写作与编辑 | 角色和总预算均生效；旧值／基线校验；编辑后事实回归 |
| 图片 | 实际读图、未知状态可见、每候选预算、人工修改不复审、跨候选参考拒绝 |
| 图文交付 | 选图不等于确认；每页确认绑定版本；单页 HTML 与 ZIP 相对引用正确 |
| 恢复 | 未知外部结果不自动重放；新上传不继承历史事实或批准 |
| 发布 | 真实 .env、数据、生成物与临时归档不进入源码包 |

## 仍有边界

macOS 启动命令和系统字体路径已提供，没有 macOS 真机结果。窄屏、键盘、长时间压力、供应商限流和多品类视觉质量未做系统统计。模型可能漏检细节；AI 视觉示意不保证实物身份，亦不能证明营销效果或搜索平台资格。

## 后续升级条件

- 有明确吞吐需求后，再开放图片并行；先验证会话隔离、配额、持久计费与中断恢复。
- 有多用户需求后，增加服务器端认证、用户／租户隔离与权限模型，再考虑外网部署。
- 扩至 100 SKU 时仍按 product 组织内容，颜色作变体、尺寸不重复生图；增加队列概览、失败重试与成本统计，而非简单放大 Agent 数量。
- 有稳定人工评价样本后，再做跨品类图文质量评测。不要通过反复降低核验标准让所有输出自动通过。
