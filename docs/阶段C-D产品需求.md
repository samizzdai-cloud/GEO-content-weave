# 产品需求：商品研究与图文生产工作台

## 目标与范围

面向需要为多个商品准备研究、Blog 和商品详情页的内容负责人，提供一个可本地运行、可检查来源、可修改并交付的工作台。成功标准是任务独立、事实可追溯、确认点明确、结果可下载；不承诺模型准确率、营销转化或搜索平台展示资格。

## 输入与任务

- 支持单商品 JSON、多文件及单文件多商品，单批最多二十项。错误项与有效项分别展示。
- 以 product 建任务和双页面；SKU 保留为变体，不额外生成文章。SKU 属性只作用于该变体，不能提升成商品通用事实。
- 品牌、商品、变体在各自范围继承；同名品牌仅组织展示，不跨来源合并事实。新上传即独立快照，历史仅追溯。
- 配置按范围覆盖；对象递归、数组整体替换，显式 null 拒绝，价格整体校验。用户看到生效值与来源。

## 人工确认与工作台

1. 程序解析、入口 Agent 检查输入；有问题时用户按原资料继续，或审阅事实／要求候选及差异后确认。
2. 研究形成问题地图、来源、编辑策略和双页规划；用户确认当前规划，随后显式启动内容生产。
3. 必要事实与结构检查通过即完成文字，可下载并继续修改；来源重合、平台资格未测等信息不额外强制人审或报警。
4. Blog／详情页 Tab 展示文字与图片卡片。生成、选择与批准含义分开；确认当前图文一次绑定眼前正文和图片，不重复审批。

任务等待处理不占执行槽，也不阻止其他商品继续。切换商品、Tab 或候选保留未提交意见。中断、失败和外部结果未知必须真实显示。

## 图片

- 同一图片 Agent 从本次商品、正文、主题、目标场景及风格构思，不使用商品专属固定模板。
- Blog 默认 16:9、不透明，提供实际使用者入镜／仅商品与场景两候选。使用者按商品判断，不固定人类、性别，也不把购买者自动当使用者；资料不足时请求补充。
- 详情图默认 1:1，可用真实透明背景；多个已确认颜色以主色在前、其余错位在后的方式展示，忽略尺寸，不虚构色款或 SKU。
- 最低可用分辨率，PNG。两页共享风格输入，不要求构图与背景完全相同。
- 自动每候选最多三次生成，Blog 两候选合计最多六次。人工修改每次只传选定候选的一张原图，生成一张后直接返回，不追加视觉自检／自动循环。
- 两候选各自保存历史、预算和草稿；另一候选完成不能抢走页级选图。用户场景排除条件只作用于当前任务。
- 展示图右下角由程序叠加半透明磨砂底“AI 视觉示意”，原图保留作参考；不以 AI 图证明实物一致性。

## 交付

文字结果含 Blog／商品 HTML、Blog Markdown 和 Product JSON-LD。每页图文确认后可独立下载嵌图 HTML；两页确认后下载含 HTML、PNG、相对引用、所有当前候选历史与生成记录的 ZIP。

用户更换正文、相关事实或选图后，旧批准不自动迁移。纯文字完成不依赖图片。确认、下载和重试不应隐式重跑研究、写作或图片生成。

## 后续范围

图片并行、长期压力、多用户部署、规模化质量评测和真实站点发布不属于当前本地单用户版本。扩展至 100 SKU 应按商品归组，不能把每个尺寸 SKU 生成一套重复文章；不要求本轮真实生成一百张图片。
