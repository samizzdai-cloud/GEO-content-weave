# 发布整理与验证

本轮整理保持 Agent 分工、事实核验、预算和用户确认语义。历史文档、探针、验收样本和迁移结果移入本地 `.local-archive/`，不删除运行数据；发布目录仅保留当前说明、正式代码、测试和示例。

运行改动包括：HTTP 客户端继承环境代理、各文本角色统一读取模型配置、`.env` 在存储初始化前加载、跨平台浏览器启动入口、Windows／macOS 中文标记字体选择。

源码包采用明确发布清单；真实 `.env`、归档、数据库、生成物及虚拟环境不进入包。打包前扫描本地已配置凭证与当前文档链接。
